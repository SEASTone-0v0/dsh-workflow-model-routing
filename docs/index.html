Design principles

把控制权留在人手里。

01 / EXPLICIT

显式，而不是自动

主用是默认入口，备用用于有证据的故障，升级用于复杂阻塞或复核打回。切换始终是可见决定。

02 / NEUTRAL

中立，而不是绑定

模式描述成本、质量与国内模型偏好，不按供应商硬编码禁用路线，也不限制用户选择。

03 / VERIFIABLE

证据，而不是假设

目录可见不代表端点健康或套餐可用；本地测试也不等同于真实 GUI 与真实模型调用。
