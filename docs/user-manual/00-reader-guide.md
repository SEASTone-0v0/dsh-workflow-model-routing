# 第 1 章　阅读指南与快速开始

## 1.1 这套系统解决什么问题

这套配置把四件容易混淆的事分开：

1. **主会话默认模型**：今后新主会话默认使用哪条模型路线。
2. **专业角色路线**：调用 `role_subagent` 时，coder、researcher 等角色使用哪条路线。
3. **授权范围**：哪些 `provider/model` 明确允许用于子代理与 AI 配置。
4. **协作过程**：任务如何拆分、认领、执行、回传和验收；共享任务记录本身不会启动 Agent。

它不接管所有模型请求，也不会因为页面里写了一个角色，就在后台自动创建该角色。

## 1.2 打开配置入口

在当前 DeepSeek Harness 桌面应用中：

1. 点击左下角账户区域。
2. 点击「设置」。
3. 在设置左侧选择「运行模式与团队路由」。
4. 页面顶部先选「经济 / 普通 / 性能 / 穷鬼」之一，再进入三个主模块之一。

当前实际渲染的三个主模块是：

| 模块 | 在这里做什么 | 不在这里做什么 |
| --- | --- | --- |
| 主会话与派工控制 | 设置 Lead 默认路线、插件派工入口、插件并发 | 不重复编辑四个协作身份；不拦截全部原生工具 |
| 模型与角色中心 | 编辑专业角色；高级区设置协作身份覆盖与协作建议 | 不把角色名称当成自动运行的 Agent |
| 模型配置 | 管理授权、能力、分层、连接测试和 AI 草稿 | 不把目录可见或市场推荐当成已验证可用 |

源码中的 `子代理配置`、`授权模型` 属于保留的旧文案；当前主导航不要按五个并列页面理解。

## 1.3 第一次使用：最短安全路径

### 场景 A：只调整今后主会话的默认模型

1. 选择目标模式。
2. 进入「主会话与派工控制」。
3. 在「Lead 主模型」选择已授权路线。
4. 推理政策不确定时选「模型默认」，不要猜档位。
5. 点击「保存设置」。
6. 检查草稿已保存，再点击「启用该模式」。

启用会改变当前模式、活动快照和今后主会话的 Lead 默认选择；不会据此承诺当前已打开会话立刻换模型。

### 场景 B：让 coder 使用固定角色路线

1. 在「模型配置」中确认目标模型已授权。
2. 进入「模型与角色中心」，找到「代码执行员 · coder」。
3. 确认「启用该角色」已勾选，设置「主用」路线。
4. 备用、升级可留空；它们不是自动故障切换。
5. 保存并启用目标模式。
6. 在当前 Agent 确实提供 `role_subagent` 时，用 `roleId="coder"` 和完整 `prompt` 派发；否则使用原生工具并明确模型参数，不能假定角色表自动生效。

### 场景 C：只整理一份材料，不需要团队协作

直接在当前会话完成即可。简单任务不要为了“用完角色”而派生多个 Agent；角色是可选分工，不是必须使用的工作流。

## 1.4 四个模式怎样理解

| 模式 | 使用意图 | 选择边界 |
| --- | --- | --- |
| 经济 | GPT 不可用或额度不足时，优先高质量、成本可控的国产模型 | 是偏好，不禁止其他已授权模型 |
| 普通 | 质量、速度、成本均衡 | 不保证固定供应商或固定价格 |
| 性能 | 复杂任务和质量优先，可采用更高推理与独立复核 | 不等于自动升级或自动多开 |
| 穷鬼 | 极限节约，优先低开销路线 | 是偏好，不再硬禁某供应商或模型 |

四套模式各自保存 Lead、角色、团队覆盖与任务目标草稿；**授权列表是全局共享的**，不是每套模式各有一份。

## 1.5 必须先分清的四个名称

| 名称 | 实际含义 | 常见误解 |
| --- | --- | --- |
| 当前主模型 | 当前这次会话实际运行的模型 | 以为它会随说明书下拉框改变 |
| 模式 Lead | 启用模式后写入的今后主会话默认路线 | 以为它就是每个子代理的模型 |
| `roleId=lead` | 可委派的“总协调员”专业角色 | 以为它会自动成为整棵 Agent 树的 root |
| `teamRole` | planner / executor / reviewer / advisor 的显式覆盖槽 | 以为页面保存后就有四个常驻 Agent |

## 1.6 三条最重要的安全规则

- **保存不等于启用**：先保存草稿，再明确启用；AI 生成也只进入草稿。
- **目录可见不等于可用**：授权、订阅权限、连接状态、输入模态和推理档位分别核验。
- **记录不等于执行**：创建任务、启动子代理、任务显示完成、业务验收通过是四个不同事件。

## 1.7 本说明书的证据范围

说明书依据当前 v2.6.4 源码、真实保存配置的只读快照与已完成的界面/回归证据编写。示例中的 SSS、A/B/C、A1/A2/A3 是讲解任务，不代表这些业务任务真实执行过。具体路线可能随用户后续配置改变，不能把说明书里的模型示例当成永久推荐或当前会话快照。
